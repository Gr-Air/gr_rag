# Spec 006: Token 爆炸修复（长文档片段提取）

> 创建日期：2026-07-01
> 状态：**implemented**
> 关联 Issue：`[BUG] Small-to-Big 扩展导致 token 爆炸`
> 实施日期：2026-07-01

---

## 1. 动机

Small-to-Big 检索策略导致单 chunk 扩展到 5 个相邻 chunk，总 token 超过 4000，超出 LLM 上下文窗口。需要改为：
1. 限制 `contextWindow=1`（不扩展相邻 chunk）
2. 命中结构化搜索文档后，只提取实体前后 ±200 token 的片段，不召回全部文档内容

---

## 2. 行为契约

### 2.1 正常路径

| 输入 | 预期输出 |
|------|---------|
| 长文档 + 实体命中 | 提取实体前后各 200 token 的片段 |
| 短文档（< 400 token） | 全文注入，不截断 |
| 实体出现在文档开头 | 提取实体后 200 token |
| 实体出现在文档末尾 | 提取实体前 200 token |

### 2.2 边界条件

| 输入 | 预期输出 |
|------|---------|
| 多个实体命中同一文档 | 合并所有命中位置的片段，去重后注入 |
| 实体跨多个 chunk | 只取包含实体的 chunk 的相关片段 |
| 实体未找到 | 回退到原始检索结果 |

### 2.3 错误处理

| 异常场景 | 预期行为 |
|----------|---------|
| 文档内容为空 | 跳过该文档，继续处理其他文档 |
| tokenizer 解析失败 | 使用字符级截取作为降级 |
