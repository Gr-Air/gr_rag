# Spec 007: 索引构建流式分批处理

> 创建日期：2026-07-01
> 状态：**implemented**
> 关联 Issue：`[BUG] Wiki 文档索引构建内存溢出`
> 实施日期：2026-07-01

---

## 1. 动机

全量索引构建脚本（`buildIndex.ts`）一次性加载 3851 个 Wiki 文档到内存，导致 Node.js 内存溢出崩溃。需要重写为流式分批处理：
1. 使用 Generator 分批生成文档块
2. 向量索引分片存储（每 1000/2000 个块一个分片）
3. 增量处理 BM25 倒排索引

---

## 2. 行为契约

### 2.1 正常路径

| 输入 | 预期输出 |
|------|---------|
| 3851 个 Wiki 文档 + 110 个 Raw 文档 | 成功构建完整索引，内存占用 < 200MB |
| 每批次 100 个 chunk | 逐步处理，内存峰值可控 |
| LanceDB 写入 | 分批追加，不一次性加载全部数据 |

### 2.2 边界条件

| 输入 | 预期输出 |
|------|---------|
| 空文档集合 | 生成空索引，不报错 |
| 超大文档（> 10MB） | 按 chunk 大小限制分割，不导致内存溢出 |
| 中断后恢复 | 支持增量构建（通过 index_state.json） |

### 2.3 错误处理

| 异常场景 | 预期行为 |
|----------|---------|
| Embedding API 调用失败 | 重试 3 次，仍失败则记录日志并跳过该批次 |
| LanceDB 写入失败 | 回滚当前批次，保留已写入数据 |
