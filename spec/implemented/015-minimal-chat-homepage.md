# Spec 015: 前端极简化 — 首页即对话框

> 创建日期：2026-06-23
> 状态：**implemented**
> 关联 Issue：`[FEAT] 前端页面优化，只保留对话框`
> 关联分支：（无需分支，直接在 main 实施）

---

## 1. 动机

当前 llm-wiki 前端有 4 个页面（首页统计面板、智能搜索、AI 问答、文档浏览）+ 顶部导航栏 + 页脚。产品核心价值是"用自然语言向知识库提问"，传统搜索和文档浏览页面是多余的噪音。需要极简化为纯对话框界面，类似 ChatGPT 风格。

## 2. 行为契约

### 2.1 正常路径

| 输入 | 预期输出 |
|------|---------|
| 用户访问 `/` | 看到纯白页面，顶部小标题"星辰Wiki"，居中欢迎语 + 输入框 |
| 用户输入问题并发送 | 走 `/api/chat` SSE 流，助手逐 token 回复，展示参考文档 |
| 用户按 Enter | 发送消息（等价于点击发送按钮） |

### 2.2 边界条件

| 输入 | 预期输出 |
|------|---------|
| 空输入 + 发送 | 按钮 disabled，不触发请求 |
| 加载中 + 再次发送 | 输入框 disabled，按钮 disabled |
| 无消息时页面 | 显示欢迎语 "今天有什么可以帮你的？" |

### 2.3 错误处理

| 异常场景 | 预期行为 |
|----------|---------|
| API 请求失败 | 显示 "请求失败: {err.message}" |
| SSE 解析错误 | 静默忽略，不影响其他 token 流 |

## 3. 验收标准

- [x] `/` 首页即对话页面，无导航栏、无页脚、无统计面板
- [x] 输入问题后能正常 SSE 流式返回答案
- [x] 参考文档卡片可折叠展开
- [x] 实体标签、结构化查询结果正常展示
- [x] 加载中状态（三点弹跳动画）正常
- [x] `/api/chat` 接口正常工作

## 6. 降级策略

`/chat`、`/search`、`/docs` 页面文件保留但路由不再挂载。如需恢复，只需在 `page.tsx` 中恢复原始内容并在 `layout.tsx` 中恢复导航栏即可。
