# Spec 005: Wiki 文档权重加成

> 创建日期：2026-07-01
> 状态：**implemented**
> 关联 Issue：`[DESIGN] 提升概念定义类文档检索优先级`
> 实施日期：2026-07-01

---

## 1. 动机

检索结果中概念类 Wiki 文档（如 RAG、Kubernetes、Docker 的定义文档）经常被 Raw 业务文档淹没，导致概念类查询的 Context Recall 和 Context Precision 指标偏低。需要通过权重加成提升概念定义类文档的检索优先级。

---

## 2. 行为契约

### 2.1 正常路径

| 输入 | 预期输出 |
|------|---------|
| `docId.startsWith('wiki_')` 的文档 | RRF 分数乘以 `WIKI_DOC_BOOST`（1.3） |
| 普通 Raw 文档 | RRF 分数保持不变 |
| 混合检索结果 | Wiki 文档排名提升，但不会超过绝对相关的文档 |

### 2.2 边界条件

| 输入 | 预期输出 |
|------|---------|
| 所有结果都是 Wiki 文档 | 保持相对顺序，都乘以相同加成系数 |
| 无 Wiki 文档匹配 | 无影响，正常返回 |
| Wiki 文档分数已最高 | 保持最高，加成后仍为最高 |

### 2.3 错误处理

| 异常场景 | 预期行为 |
|----------|---------|
| `docId` 格式异常（无前缀） | 按普通文档处理，不加权 |

---

## 3. 验收标准

- [x] `src/lib/hybridSearch.ts` 中定义 `WIKI_DOC_BOOST = 1.3`
- [x] RRF 融合时对 `docId.startsWith('wiki_')` 的结果应用权重加成
- [x] 加权后的分数不超过最大可能值（归一化保护）
- [x] 概念类查询（如"什么是 RAG"）优先返回 Wiki 定义文档
